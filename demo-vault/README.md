# Advanced Markdown Export demo vault

This is an [Obsidian](https://obsidian.md/) vault demonstrating features of the [Advanced Markdown Export](https://github.com/mnaoumov/obsidian-advanced-markdown-export) plugin.

## Opening this vault

- **If you already have the plugin installed**, run the **Advanced Markdown Export: Open demo vault** command — it downloads and opens the latest demo vault automatically.
- **Otherwise**, download `advanced-markdown-export-demo-vault.zip` from the [plugin releases](https://github.com/mnaoumov/obsidian-advanced-markdown-export/releases), unzip it, and in Obsidian choose `Manage vaults...` → `Open folder as vault` → select the `advanced-markdown-export-demo-vault-<version>` folder it unzips into.

On first open, Obsidian treats the vault as untrusted — choose **Trust author and enable plugins** (or enable Community plugins manually), then open [00 Start](<./00 Start.md>).
