# Export with Dependencies demo vault

This is an [Obsidian](https://obsidian.md/) vault demonstrating features of the [Export with Dependencies](https://github.com/mnaoumov/obsidian-export-with-dependencies) plugin.

## Opening this vault

- **If you already have the plugin installed**, run the **Export with Dependencies: Open demo vault** command — it downloads and opens the latest demo vault automatically.
- **Otherwise**, download `export-with-dependencies-demo-vault-<version>.zip` (`<version>` is the release version) from the [plugin releases](https://github.com/mnaoumov/obsidian-export-with-dependencies/releases), unzip it, and in Obsidian choose `Manage vaults...` → `Open folder as vault` → select the unzipped folder.

On first open, Obsidian treats the vault as untrusted — choose **Trust author and enable plugins** (or enable Community plugins manually), then open [00 Start](<./00 Start.md>).
