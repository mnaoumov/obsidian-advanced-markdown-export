# Start here

Welcome to the [Export with Dependencies](https://github.com/mnaoumov/obsidian-export-with-dependencies/) demo vault. The plugin exports a note together with the files it depends on — its attachments, and optionally the notes it links — and lets you decide file by file what travels with it.

This vault ships a small graph with a cycle and a diamond in it, so you can watch the tree handle both instead of taking the README's word for it.
